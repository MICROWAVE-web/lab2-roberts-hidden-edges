# Лабораторная работа 2 — алгоритм Робертса

Удаление невидимых рёбер **выпуклого** тела с динамикой (вращение).

Вариант 2 задания. База преобразований/проекций — как в ЛР1 (`math3d.py`).
Буква «А» из ЛР1 невыпуклая, поэтому объект — параллелепипед (6 граней) или пирамида (5 граней).

## Запуск

```bash
./run.sh
# или
/usr/local/bin/python3 main.py
```

## Управление

| Действие | Клавиши |
|----------|---------|
| Анимация вращения | Пробел |
| Показать скрытые рёбра (пунктир) | H |
| Нормали граней | N |
| Параллелепипед / пирамида | B / P |
| Проекция | 1 ортогональная, 2 перспектива |
| Вращение мышью | ЛКМ |
| Перенос / масштаб | WASD, Q/E, колесо |
| Сброс | 0 |

## Алгоритм (кратко)

1. Для каждой грани — внешняя нормаль.
2. Грань **лицевая**, если `n · to_eye > 0`, иначе **тыльная**.
3. Ребро **невидимо**, если обе смежные грани тыльные.
4. Иначе ребро **видимо** (в т.ч. контур front+back).

Справа в окне — панель демонстрации: статус граней и рёбер в реальном времени.
